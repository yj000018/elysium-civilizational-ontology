# Pattern — Futures learning journey (draft)

**Status:** DRAFT pattern, not canon. **Provenance:** FiF prototype spec, "The Lab" (January 2026).

## Shape
- Durations: **7 / 14 / 30 / 90 days**.
- Each day has four steps:
  1. **Morning Brief** — one key concept with its context.
  2. **Core Module** — a deep dive.
  3. **Reflection Prompt** — personal application.
  4. **Action Item** — one skill or piece of knowledge to build.
- Progress is shown on a visual timeline; a completed journey closes with a short synthesis.
- **Cross-domain programs** combine two domains (example: "AI + Biotech Convergence"), using the Systems Weave mode (see the book's exploration modes).

## How it maps to ELYSIUM
- One journey = one domain (or one pair of domains) from [FIF_TRANSFORMATION_DOMAINS.md](../02_ONTOLOGY_AND_KNOWLEDGE/FIF_TRANSFORMATION_DOMAINS.md).
- Morning Brief / Core Module draw on the chapter for the foundation; the Reflection Prompt can reuse the book's daily futures prompts.
- The weekly rhythm can close with a scenario exercise (Implications Engine).
